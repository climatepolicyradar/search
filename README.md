# Search

Full-text search across the world's climate laws, policies, litigation and
finance documents — down to the exact passage, filterable by expert-curated
concepts.

## API

Base URL: `https://api.climatepolicyradar.org/search`. No authentication.

- [llms.txt](https://api.climatepolicyradar.org/search/llms.txt) — how to query
  the API, written for LLMs and agents: the data model, the `filters` grammar,
  sorting, pagination and corpus freshness [api/routers.py](api/routers.py).
- [OpenAPI schema](https://api.climatepolicyradar.org/search/openapi.json)
- [Interactive docs](https://api.climatepolicyradar.org/search/docs)
- [ReDoc](https://api.climatepolicyradar.org/search/redoc) as an alternative.

## Prerequisites

- [Vespa CLI](https://docs.vespa.ai/en/clients/vespa-cli.html#install-configure-and-run)
